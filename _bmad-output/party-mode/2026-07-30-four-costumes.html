Four Costumes

The night a job-discovery routine failed four different ways, and every failure turned out to be the same four hundred characters wearing a new disguise.

The reveal

633 against 8,500

Fourteen postings had been staged into the pipeline overnight. Every one scored 0/100. Every one said no salary stated. It looked like fourteen bad jobs. One LENGTH(raw_text) query said otherwise.

One bug

The costumes, in order

  1. A rate limit

    Indeed throttled the run. Real, but a symptom — the routine was re-fetching details for jobs it had already staged.

  2. An improvisation

    Blocked, the agent wrote itself a recovery script that condensed every description into an intermediate file. That is where the text died.

  3. Fourteen confident zeros

    The scorer did its job perfectly on nothing at all. Absence of information rendered as a verdict.

  4. A very nearly irreversible delete

    Which almost became a rule that auto-deleted every job scoring under 85 — on a database with one copy and no backup.
